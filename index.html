Getting Started

Learn how this starter project is structured and what is needed for production.

Quick Start

  1. Open the web/ folder.
  2. Serve index.html locally or deploy it as a static site.
  3. Create a project from the dashboard.
  4. Try the Code Editor, Visual Builder and Website-to-App settings.
  5. Read the root README to connect an actual build backend.

Production Requirements

  • Real authentication and database rules.
  • Backend API and private artifact storage.
  • Isolated Android build workers.
  • APK verification and safe release signing.
  • Quotas, logs, monitoring and backups.
