# WebView Android Template

This is a source starter, not a standalone Gradle project yet. To compile it, add a Gradle wrapper, root/app Gradle build files, a pinned Android Gradle Plugin version, Kotlin plugin, and SDK configuration appropriate for your environment. The `example.com` allowlist is intentionally restrictive and must be configured from trusted, validated project settings by the build worker.

Never allow arbitrary remote URLs to use a JavaScript bridge. Validate external navigation and use HTTPS.
